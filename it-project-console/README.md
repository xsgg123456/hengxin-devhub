# IT 项目管理台

本目录承载产品代码，与仓库根目录的需求、设计、计划和 Harness 共用同一个 Git 根。

## 本地开发

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

前端原型模式使用浏览器本地数据，提供四个固定演示账号、刷新持久化和一键重置。生产构建不会包含演示身份或 Mock 数据回退。

访问 `http://127.0.0.1:4317/`。顶部用户菜单切换演示身份。

## Phase 2 体验路线

1. 切换李思敏，在需求池保存草稿或提交正式需求；PRD、HTML 各提供 HTTPS 链接或模拟文件。
2. 切换陈立峰，评估需求，选择王浩然为主负责人、赵清越为协作人员并设置两类计划日期，完成立项。
3. 切换王浩然，在“我的项目”更新整体进度；阶段完成后顺序进入下一环节，日期调整须说明原因。
4. 切换赵清越，只能为该项目补充个人进展或阻塞；切回陈立峰查看同一项目的风险、日期与更新记录。
5. 刷新保留结果；需要重新演示时在身份菜单中确认重置。

管理人员也可直接创建项目。三类角色均能查看全部需求和项目，默认筛选与写权限分别控制。

目前交付的是跨角色核心闭环。完整统计图表、人员负载、待办、甘特及生命周期操作按 Phase 3 继续实现；真实后端在领导确认前端评审版后进入开发。
