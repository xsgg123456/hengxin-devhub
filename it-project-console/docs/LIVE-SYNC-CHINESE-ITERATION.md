# 中文业务提示与跨用户同步

用户于2026-09-15授权本地开发，两项一并验收；本轮不自动发布生产。

## 需求与验收

1. 普通及优化需求的失焦、变更、提交校验均为中文；草稿仍允许不完整，优化附件仍可选。日期调整记录正确显示审批确认上线日期；历史系统字段、动作和枚举用中文映射与安全兜底，保留用户自由文本、产品名和链接。
2. 服务端提供已登录用户的SSE变更信号，仅包含不透明版本，不广播业务内容；写入成功提交后才可见。客户端收到信号重新调用现有鉴权数据接口。正常前台联网目标1–3秒看到更新。
3. 需求、审批、项目排期、进展、验收、人员权限变化均同步到现有列表、统计、待办、详情和甘特图。保持筛选、滚动和抽屉；后台更新不清空原内容、不反复闪烁加载占位。
4. 未保存字段和上传队列不被同步覆盖；同条记录变化提示中文冲突并保留原版本校验，不能把旧输入以新版本静默覆盖。删除及权限变更也必须安全处理。
5. 断线重连、页面回到前台、网络恢复时补同步；每30秒轻量版本检查兜底。避免重复并发及过期响应覆盖；退出登录、隐藏及卸载清理连接。会话失效遵循既有登录流程。
6. 原型模式保持现有本地行为。生产代理支持流式响应，不缓冲事件。
