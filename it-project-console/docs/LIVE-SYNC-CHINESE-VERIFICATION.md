## 实现

- 需求表单显式中文校验覆盖失焦、日期变更和提交；不改变普通附件必填、优化附件可选、草稿允许不完整的规则。
- 日期调整记录补齐审批确认上线日期，未知系统字段和历史阶段使用中文兜底；历史需求状态兼容 APPROVED。自由描述和链接保留。
- 数据库14个业务源表使用事务提交时的延迟触发器更新持久UUID版本。API每秒共享读取版本并校验在线会话，SSE只发送版本；数据通过原鉴权接口重读。两层Nginx禁缓冲。
- 前台保持一条SSE连接，30秒轻量版本兜底，重连/焦点/联网恢复补拉，隐藏/退出清理。查询失败每30秒重试；同筛选后台不清列表、不展示初始加载占位；账号切换清旧数据。
- 原需求、评估、项目编辑、计划、进度、接单表单冻结编辑版本；同步不重置输入和上传队列，外部删除保留编辑副本并阻断旧保存。验收沿用已有显式确认版本保护。
- 权限变化更新菜单和页面权限边界；管理名单接入已有查询刷新机制。
