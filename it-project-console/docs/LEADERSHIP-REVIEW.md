# 前端领导评审路线

版本日期：2026-09-08。评审入口：http://127.0.0.1:4317/ 。这是本地前端演示版，当前浏览器内共享演示数据；附件只保存演示元数据，尚未连接钉钉登录、服务端和真实文件存储。

## 连续操作路线

建议在桌面浏览器宽度 1280px 或 1440px 下操作，预留 15 分钟。右上角姓名打开原 Art Design Pro 用户菜单，可切换四个演示账号、演示场景和重置数据。

1. **回到起点**：在用户菜单选择“重置演示数据”，确认后恢复固定项目和需求，保留当前演示账号。重置会清除当前浏览器的演示记录，评审过程中有需保留的内容时先记录。
2. **业务提交**：切换李思敏，进入“我的需求”，点击“提交正式项目需求”。填写“评审预算协同项目”、一句话问题、晚于当天的期望上线日期，分别提供 PRD 和 HTML 原型 HTTPS 链接，提交评估。确认列表出现“待评估”。
3. **管理立项**：切换陈立峰，进入“我的需求”，找到同名需求并“评估”。选择王浩然主责、赵清越协作，填写方案设计预计完成、计划上线和计划交付日期，点击“通过并立项”。确认需求变成“已立项”，生成唯一项目。
4. **主责更新**：切换王浩然，在项目卡片点击“更新进度”，将整体进度设为 63%，阶段状态选择“已阻塞”，填写阻塞原因和进展说明后保存。确认卡片显示 63% 和阻塞提示。
5. **协作补充**：切换赵清越，找到同一项目并“填写协作进展”，保存一条协作说明。确认无法修改整体百分比，主责刚保存的整体进度和状态仍然保留。
6. **管理查看**：切换陈立峰，用项目名称搜索；检查风险标记、项目分布和人员负载。点击负载数字进入项目明细，确认主责与协作分别计算、协作说明可见。进入“月度甘特”，打开同一项目核对 63% 和阻塞原因。新项目从立项月份开始占用负载；切换月份可查看计划区间。
7. **刷新核对**：刷新浏览器，重新打开项目详情，确认进度、协作说明和身份未丢失；切换到业务身份也能看到该项目的只读详情。
8. **恢复起点**：完成记录后再重置，确认测试项目消失、原始项目回归、筛选条件清除。

## 异常状态检查

在用户菜单“演示场景”依次选择加载中、空数据、网络错误、无权限，核对页面提示，并使用“恢复正常”回到原记录。空数据是显示投影，不删除已保存数据。

选择“保存失败”后编辑需求或更新进度并保存，确认显示失败、输入保留、数据未被写入；在编辑界面恢复正常后重新保存。提交中按钮应锁定，连续点击不能产生重复记录。切换会丢弃输入的场景、身份或页面时应出现未保存提醒。

读取损坏数据时会出现恢复页，可先“重新读取”，也可经确认重置。取消重置必须保留原数据。该情况由隔离浏览器自动化注入验证，日常评审不必手动修改浏览器存储。

生产构建只显示“企业登录暂未开放”，没有演示身份、场景菜单或 Mock 回退。真实登录与持久化属于后续后端阶段。
