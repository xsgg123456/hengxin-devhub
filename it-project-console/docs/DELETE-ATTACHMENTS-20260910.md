# 删除权限与统一附件验收（2026-09-10）

本次按 Product-Spec.md 的同日变更实施；代码与配置尚未部署到生产。

## 已实现

- 管理人员删除任意需求/项目；业务人员删除本人需求及其关联项目，不限状态。原需求与关联项目整体删除，清理进度和附件，保留独立审计。需求列表、需求详情和项目详情提供删除入口，确认框说明影响。
- 原需求抽屉统一为一个多选/拖拽附件入口，不限制文件扩展名或 MIME。正式提交/重新提交至少一个上传完成文件；草稿可为空。显示上传进度、失败重试与移除，保存失败保留输入。
- 单文件 100 MB（104857600 字节），单需求 500 MB（524288000 字节）。旧 PRD/原型文件迁入统一列表，旧链接仍可读；新附件默认鉴权下载。
- 删除与通知发送使用同一事务级锁。发前重新读取内容，取消未发送项；已受理或结果不明的通知保留投递事实，摘要移除被删项目，避免过期内容重发。
- 已保存的文件先从列表移除、保存后才释放服务端额度。页面在移除旧文件后提示这一规则；新增但未保存的文件由原清理机制回收。
