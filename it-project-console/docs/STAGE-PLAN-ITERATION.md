# 2026-09-11 已确认：先排期后执行、需求池统一筛选

本文件为本轮确认条款原文；Product-Spec、Design-Brief、DEV-PLAN 引用本文件。与旧版人工百分比、滚动填日期、二次完成/自动归档规则冲突时，以本轮为准。

## 需求与验收

1. 管理立项取消最初计划上线、最初计划交付、方案设计预计完成三个输入及必填校验；保留决定、优先级、唯一主负责人、协作人员。直接创建项目走同一待排期流程。
2. 新项目：需求受理、立项评审完成并记录真实时间；主负责人（及既有管理权限）一次安排后五阶段的计划开始/结束，完整提交前不能执行整体完成更新。阶段顺序固定，开始不得晚于结束，后阶段不得早于前阶段结束（允许同日交接）。
3. 已有项目不伪造已完成阶段日期；只补当前和后续未完成阶段。既有实际记录不覆盖，未知显示“—”。已完成项目缺少真实实际完成时间不使用 updatedAt 兜底。
4. 计划和执行入口分开。首排无需改期原因；后续调整须填原因及说明，保存字段级旧值/新值、人员、时间；保留最初计划。完成情况用最新计划比较。已完成阶段计划不可常规改写。
5. 日常更新当前环节“尚未完成/已完成”，说明选填；个人协作进展保持原权限。整体更新不填百分比或日期，完成操作由服务端记录作者和时间并按原计划进入下一环节。
6. 验收交付完成时自动完成项目并记录 actualCompletedAt，不再第二次点完成项目，不自动归档。取消/重新打开/手动归档保留既有权限。重新打开清除当前完成结果但保留历史；重新完成再记录新的实际时间。
7. 移除卡片、详情、甘特图及管理纠正中的人工整体百分比输入和展示，保留阶段状态、计划、历史。旧百分比可保留历史存储兼容，但不得参与新逻辑或冒充实际进度。
8. 详情原位改为七环节表：环节、计划开始→结束、状态、实际完成日；系统前两环节无工程师计划。继续显示更新、管理和日期调整记录。上线/交付当前计划由对应阶段结束日带出。
9. 需求池自上而下为提交通道、统一筛选、指标、分布与月度趋势、清单。筛选含部门、提出时间、需求状态、完成情况，保留本人/全部和重置；移除旧清单独立关键词框，不残留隐藏关键词过滤。
10. 统计、图表、悬停明细、清单共享筛选全集；指标不按分页计算。提出时间按上海日历日期含首尾；无提交时间不命中日期筛选。无结果统一为0/空态，清空恢复。未选区间趋势近六个自然月，选区间按区间月份含零值月份。
11. 需求清单显示工程师验收交付计划结束日、实际完成日、完成情况；实际完成按上海日期与最新计划比较，早于/等于为正常完成，晚于为延期完成，未完成显示未完成，已完成但缺任一必要日期显示“—”不参与两类筛选。业务期望上线只作参考。
12. 原型与真实API行为一致，服务端校验权限/版本/幂等、全量排期和日期顺序。事务保存项目/阶段/日志，重试不重复完成或重复发通知。

## 实现契约与原位复用

- Project 新增 stagePlans 数组（stage/startDate/endDate/originalStartDate/originalEndDate）和 actualCompletedAt 可空时间；workspace/dashboard project读模型均提供。是否待排期按当前及后续阶段计划完整性推导。
- POST /api/projects/:id/plan：requestId、version、plans（stage/startDate/endDate）、可选 changeReason/changeDescription，成功返回 id/version。阶段日期调整记录字段 stage:<阶段>:startDate/endDate，现有字段兼容。
- progress接口继续 kind/status/summary/blocker，请求不再依赖百分比及日期。
- demand-statistics查询补 from/to/completion（空/normal/late）；需求行增加 plannedCompletionDate、actualCompletedAt、completionStatus（normal/late/unfinished/unknown）。
- 原位文件：project-fields、demand-review、progress-update-drawer、project-detail-drawer、stage-history、project-card、monthly-gantt；保留母版760px抽屉、Element Plus、主题和错误/加载/权限逻辑。现有执行表单无法承载独立五阶段排期，可新增专用排期表单并复用原抽屉/日期组件，不另造壳。
- 需求池沿用 my-demands/index、use-demand-page、demand-charts，统一服务端筛选和统计。
